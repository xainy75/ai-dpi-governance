# AI for Digital Public Infrastructure & Governance (AI-DPI)

[![React](https://img.shields.io/badge/React-19.0-61DAFB.svg)](https://react.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4-38BDF8.svg)](https://tailwindcss.com/)

A modern, trustworthy, content-rich web application and architectural reference model for **"AI for Digital Public Infrastructure & Governance"**. This platform showcases how sovereign Artificial Intelligence layers onto foundational Digital Public Infrastructure (DPI) stacks—digital identity, instant payment rails, and consent-based data exchange—to deliver fraud-resistant, inclusive public services across emerging economies like Pakistan.

---

## 🌟 Key Highlights & Features

- **Interactive Canvas Network Motif**: Real-time particle network background symbolizing infrastructure nodes, data connections, and AI mesh telemetry.
- **DPI + AI Pillars Deep Dive**: Comparative analysis of traditional vs. AI-enhanced identity verification, payment rails, and data exchange networks.
- **6 Real-World Use Case Blueprints**: Technical specs, implementation prerequisites, and measured civic impact for:
  1. AI Digital ID Verification & Liveness Detection
  2. Fraud & Leakage Detection in Welfare Payments
  3. Conversational Voice/Text AI for Citizen Services
  4. Predictive Analytics for Public Health & Agriculture
  5. Semantic Interoperable Data Exchange between Ministries
  6. Smart Executive Policy Dashboards
- **Non-Image Layered Stack Architecture**: Interactive 4-layer SVG & HTML/CSS reference model (Foundational DPI → AI/ML Engine → Application Delivery → Governance & Ethics) with a live module inspector.
- **Pakistan & Emerging Market Case Studies**: National-scale models for **NADRA Digital ID**, **Ehsaas/BISP Payout Fraud Prevention**, and **Voice-Activated Dialect AI for Rural Farmers**.
- **Filterable Research Repository**: Analytical briefs and policy notes with category filters, text search, and full-article markdown reader modals.
- **Animated Impact Counters**: Scroll-triggered numerical counters featuring clear illustrative reference statistics.
- **Functional Institutional Contact Form**: Client-side validation with real-time feedback, submission success confirmation, and policy newsletter subscription.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/xainy75/ai-dpi-governance.git
   cd ai-dpi-governance
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser to view the application.

4. **Build for production**:
   ```bash
   npm run build
   ```
